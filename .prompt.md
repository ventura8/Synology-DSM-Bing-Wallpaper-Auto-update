# Prompt Presets

## Maintenance Mode
Audit and improve code quality while preserving behavior. Enforce required linting and formatting without adding suppressions or bypasses.

## CI Debug Mode
Diagnose failing CI jobs by reproducing checks locally, starting with mandatory quality gates and then test or coverage stages.

## Lint Fix Mode
Apply formatter output first, then resolve remaining lint findings in deterministic order: shell, Python, PowerShell, YAML, workflows.

## Coverage Mode
Keep threshold at 90 percent or higher and validate report transformation scripts remain stable in local and CI execution.

# Prompt Presets

Follow [`AGENTS.md`](AGENTS.md) and [`.agents/skills/`](.agents/skills/). Prefer the
matching skill when one exists (`code-linter`, `test-runner`, `pipeline-runner`,
`ci-maintainer`, `release`, `release-hygiene`, `resolve-pr-comments`,
`review-with-coderabbit`).

## Maintenance Mode

Audit and improve quality while preserving behavior. No suppressions.

## CI Debug Mode

Reproduce CI locally: quality gate first, then tests/coverage
(`pipeline-runner` / `ci-maintainer`).

## Lint Fix Mode

Autofix first, then remaining findings (`code-linter`).

## Coverage Mode

Keep ≥90% coverage; commit `assets/coverage.svg` after local regeneration
(`test-runner`).

# v1.0.1 - Quality, CI, and Agent Workflow Hardening

## Summary
This release hardens repository quality controls by making linting and formatting mandatory in both local development and CI, enforcing a 140-character maximum line length for all non-Markdown text files, upgrading CI dependencies to stable versions, and introducing comprehensive project-level agent and skill guidance.

## Why This Change
- Eliminate drift between local checks and CI checks.
- Enforce consistent formatting and static analysis across Shell, Python, PowerShell, YAML, and workflow files.
- Remove high-risk CI dependencies and unpinned behavior.
- Provide explicit AI agent operating guidance and reusable skills for maintenance workflows.

## What Changed

### 1. Mandatory Quality Toolchain
- Added shared quality configurations:
  - `.editorconfig`
  - `pyproject.toml` (Ruff + Mypy config)
  - `.shellcheckrc`
  - `.yamllint.yml`
  - `.psscriptanalyzer.psd1`
  - `requirements/dev.txt`
- Added mandatory local quality commands:
  - `scripts/quality/quality_check.ps1`
  - `scripts/quality/quality_check.sh`
- Added custom non-Markdown line-length enforcement (`<= 140`):
  - `scripts/quality/check_line_length.py`

### 2. Pre-commit Enforcement
- Added `.pre-commit-config.yaml` with mandatory hooks for:
  - `shfmt`
  - `shellcheck`
  - `ruff` + `ruff-format`
  - `mypy`
  - `yamllint`
  - `PSScriptAnalyzer`
  - `actionlint`

  - `scripts/lint/lint_actions.py`

  - `scripts/lint/lint_powershell.ps1`

### 3. CI Hardening and Dependency Updates
- Reworked CI workflow in `.github/workflows/ci.yml`:
  - Added dedicated `quality` job required by test jobs.
  - Updated action versions to stable patch releases (balanced pinning).
  - Kept unit/component/e2e coverage flow and reporting pipeline.
- Replaced risky floating coverage action with explicit threshold validation:
  - `scripts/coverage_checks/check_coverage_threshold.py`
- Improved workflow shell safety and quoting so `actionlint` and shell analysis pass reliably.

### 4. Test Runtime and Coverage Stack
- Updated test container base image to `ubuntu:24.04`.
- Pinned `kcov` to `v42` in `tests/Dockerfile.dsm_mock`.
- Updated `scripts/testing/run_tests_local.ps1`:

  - line-length-compliant execution flow

## Policy Guarantees Added by This Release
- No lint suppressions or disable directives introduced.
- Local and CI quality checks are equivalent and mandatory.
- 140-character maximum line length enforced for all non-Markdown text files.

## Notes
- Markdown files are intentionally excluded from line-length enforcement by policy.

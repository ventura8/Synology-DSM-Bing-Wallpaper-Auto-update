# Skill: Testing and Coverage

## Objective
Ensure test execution and coverage reporting remain reliable and enforce minimum threshold requirements.

## Required Steps
1. Run mandatory quality checks.
2. Run local test orchestration script.
3. Validate transformed cobertura output.
4. Enforce line coverage threshold at 90 percent.

## Output Requirements
- Coverage threshold pass.
- Updated coverage badge when regenerated.
- No change in functional test behavior.

# Repository AI Instructions

## Quality Gates Are Mandatory
- Always run full quality checks before tests or feature validation.
- Run local gate with PowerShell: ./scripts/quality/quality_check.ps1
- Run local gate with Bash: ./scripts/quality/quality_check.sh
- No lint suppressions, no disable directives, and no ignore-based bypasses are allowed.

## Formatting and Linting Standards
- Maximum line length is 140 for all non-Markdown text files.
- Markdown is excluded only from line-length enforcement.
- Required tooling:
  - Shell: shfmt and ShellCheck
  - Python: Ruff, Mypy
  - PowerShell: PSScriptAnalyzer
  - YAML and GitHub workflows: yamllint and actionlint
- Pre-commit configuration is the source of truth for mandatory checks.

## CI and Local Parity
- CI must execute the same mandatory checks defined in pre-commit.
- Local workflows must run quality checks before tests.
- Coverage gate is required and must remain at or above 90 percent.

## Testing Workflow
1. Run quality checks.
2. Run local test pipeline.
3. Update coverage badge when coverage is regenerated.
